## 🧭 How I build

1. **I own the product thinking** — flows, rules, edge cases, pricing logic
2. **AI writes the code** — I direct, review outputs, and iterate
3. **I test everything myself** — before any team member touches it
4. **Ship small, ship often** — versioned drops, real users, fast feedback

If you're a founder who thinks you can't build software because you can't code — you can. The bottleneck was never syntax. It's clarity of thought.
